When Documentation Changes (kb/)

<60s Upsert

Single-document incremental upsert via content fingerprinting and LiteLLM:

  • Content Fingerprinting: Diff algorithm detects exact file additions, modifications, renames, and deletions.
  • Single-Doc Incremental Upsert: Directly triggers memory_upsert_document via LiteLLM proxy (https://litellm.labs.jb.gg/v1).
  • Zero Heavy Rebuilds: Chunks, embeds, and merges only changed markdown files into the HARS Long-term Memory knowledge graph and Qdrant pier_kb_v2 collection.
  • Automated Purge: Renamed or deleted runbooks are instantly purged via memory_delete_document.
  • Outcome: Engineers querying troubleshooting guides never read outdated incident steps.
Tool: memory_upsert_document · Model: openai/gpt-5.6-luna

When Repository Code Changes (repos/*)

Real-Time AST Sync

Incremental AST compiler re-parsing and vector updates:

  • Remote Trigger API: Triggers remote Code-Diver reindexing via POST /api/v1/index/trigger with repository path and AST graph parameters.
  • Tree-sitter AST Extraction: Parses updated functions, structs, interfaces, and call graphs for Go, Python, TypeScript, Java, and Kotlin.
  • Line-Bounded Vector Refresh: Updates the shared Qdrant vector store and LightGBM cross-encoder reranking cache.
  • Zero Stale Code Queries: Coding agents never hallucinate deleted methods or query non-existent Go structs.
  • Outcome: High-precision compiler understanding always matches origin/master.
API: POST /api/v1/index/trigger · Endpoint: knotgate.labs.jb.gg

Ready In 30 Seconds · Single CLI Commands

Add to Your Agent With a Single Terminal Command

No JSON editing required. Run the command in your terminal and your agent is immediately connected to shared enterprise memory and code search.

Run these two commands in your terminal: 

opencode mcp add hars-longterm-memory --url https://knotgate.labs.jb.gg/memory
opencode mcp add code-diver --url https://knotgate.labs.jb.gg/code-diver/sse
✓ Automatically configures Streamable HTTP and SSE MCP transports in ~/.config/opencode/config.json.
Tokens are never baked into pages. Supply your own via env, e.g. export HARS_MEMORY_ACCESS_TOKEN=... CODE_DIVER_TOKEN=... and reference $HARS_MEMORY_ACCESS_TOKEN / ${CODE_DIVER_TOKEN} in configs.

Run in your shell to register tools with Claude Code CLI: 

claude mcp add hars-memory https://knotgate.labs.jb.gg/memory
claude mcp add code-diver https://knotgate.labs.jb.gg/code-diver/sse
✓ Immediately binds tools for your Claude Code sessions with zero restart downtime.
